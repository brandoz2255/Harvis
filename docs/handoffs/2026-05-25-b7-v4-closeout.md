### Run 3 reasoning-override finding (worth highlighting)

The MCQ #1 reliability check showed 2/3 LLM Agent on gemma4 at `tool_choice=auto`. The interesting failure is Run 3:

- Model called `web_search` voluntarily ✓
- Got real OWASP/security results back ✓
- Acknowledged in its summary that "the LLM Agent is the initial point of failure" ✓
- **Then derived its own "where the data leak actually happens" threat-model reasoning** and concluded API Gateway was more exposed ✗

This is NOT an architectural failure. Tool was called, results integrated, model reasoned over them — then preferred self-derived logic over retrieved evidence. That's a model-class reasoning calibration property, not something more middleware solves. Phase 3 reasoning-override investigation is scoped to design experiments here (temperature sweep, "weight retrieved sources over priors" prompting, retrieval reranking) — but the honest path may be "document as known model limitation."
